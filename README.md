# 📄 Resume Analyzer AI Chatbot

An intelligent web app that analyzes your resume against a job description using NLP, deep learning (BERT), and OpenAI's GPT-4 — then helps you improve it through an interactive chatbot.

---

## 🚀 Features

✅ Upload your **resume (PDF/DOCX)**  
✅ Paste any **job description**  
✅ Get a **match score** (TF-IDF or BERT)  
✅ Receive **AI suggestions** to improve your resume  
✅ Chat with a **GPT-4-powered AI assistant** about your resume  
✅ Memory-aware conversation (retains context)  
✅ Logs your conversation to `chat_logs.txt`

---

## 🧠 Tech Stack

- **Python 3**
- **Flask**
- **OpenAI API (GPT-4)**
- **Sentence Transformers (BERT)**
- **PDFMiner / python-docx**
- **Bootstrap 5 (UI)**
